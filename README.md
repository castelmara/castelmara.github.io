# ATLAS / Castelmara — обновление 23.09.2026

## Установка

1. В Supabase откройте **SQL Editor → New query**, вставьте целиком файл `sql/20260923_community.sql` и нажмите **Run**. Дождитесь успешного выполнения.
2. Загрузите содержимое этой папки в корень репозитория сайта с заменой файлов. Обязательно загрузите папки `assets` и `data`: одного `index.html` недостаточно. Папки `sql` и `verification` служат для установки и проверки; публиковать их на сайте необязательно.
3. Удалите из репозитория старую копию `index(6).html` и файл `nnnn`, если они там остались. Дождитесь сборки GitHub Pages и обновите страницу без кеша.

Обновление подготовлено для схемы из переданного `supabase.zip`. SQL выполняется одной транзакцией. Роли аккаунтов и уже полученные достижения не меняются. Первый запуск переносит составы из таблицы; повторный запуск не возвращает записи, которые администратор затем удалит из состава.

## Анкеты персонажей

Привяжите персонажа к зарегистрированному аккаунту через существующий раздел управления персонажами игрока. Для владельца внутри полной анкеты появится кнопка **редактировать анкету**. Доступ проверяет база по `character_owners.user_id`.

В редакторе можно менять фотокарточку и баннер внутри анкеты, возвращать исходные изображения, добавлять и убирать связи. Фото каталога хранится отдельно и остаётся выбранным администрацией. Изображения загружаются через обычный выбор файла с телефона или компьютера; поддерживаются JPG, PNG, WEBP и GIF до 8 МБ. При одновременном редактировании в двух окнах позднее сохранение предложит заново открыть анкету.

Имя и никнейм владельца в карточке и блоке игрока берутся из зарегистрированного профиля. Старые текстовые подписи сами по себе не назначают владельца. Короткие карточки без полной анкеты остаются короткими карточками.

Можно добавить участника, изменить команду, позицию и капитанство, скрыть запись или убрать её. В каждом составе и каждой группе поддержки может быть один видимый капитан; перед назначением нового нужно снять роль с прежнего.

## Заметки и избранное

Старые и новые заметки по умолчанию личные. При создании заметки о профиле можно включить **публичная заметка**. В личном ATLAS у заметки появилась кнопка изменения, включая видимость. Публичные заметки с указанием автора видны в соответствующем профиле; показаны последние 100 записей.

В профилях игроков и персонажей появился анонимный счётчик избранного. Список аккаунтов, сохранивших профиль, не выдаётся. Старый переключатель публикации избранного убран.

## Сообщения и настроение

Верхняя кнопка с самолётиком открывает сообщения. Компактная область показывает либо список чатов, либо переписку; назад возвращает стрелка. Отдельной боковой панели чатов нет.

Индикатор набора появляется при вводе текста, исчезает после паузы примерно в 3,6 секунды, отправки или ухода. При потере соединения чужой индикатор истекает примерно через 5,5 секунды. Стабильная сортировка чатов и сохранение положения прокрутки сохранены.

Настроение выбирается сервером из 60 пар "настроение + пояснение", один раз в день по времени Europe/Madrid. На телефоне и компьютере результат у одного аккаунта одинаковый. Вчерашний результат исключён из следующего выбора. Если на сегодня уже был записан результат старой версии, он сохранится до смены дня.

## Очистка

Удалены 22 персонажа: 11 незачёркнутых канонов со скриншота и 11 карточек, связанных с четырьмя указанными именами игроков. Сердрик Джой сохранён. В переданных данных действующих анкет с типом "лицеист" не найдено. Упоминания лицея в истории мира и биографиях сохранены.

Удалённые персонажи исключены из активных составов и привязок. Их старые сообщения сохраняются вместе с архивной личностью отправителя, чтобы не разрушить историю переписки. Они не предлагаются для добавления в новые чаты.

Обновлены тексты всех 47 достижений из CSV с сохранением ID, кодов, секретности, персональных владельцев и условий выдачи. Русский CSV находится в `sql/achievements_ru.csv`; отдельно импортировать его после SQL не требуется. Обычные английские подписи и служебные подсказки в интерфейсе переведены; собственные имена и названия разделов в испанском стиле сохранены.
