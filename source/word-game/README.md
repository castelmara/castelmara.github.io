# ATLAS word-game dictionary

Source: [OpenRussian / Badestrand russian-dictionary](https://github.com/Badestrand/russian-dictionary), `nouns.csv`, downloaded 2026-11-12.
Dataset copyright: OpenRussian contributors; licensed CC BY-SA 4.0 (see LICENSE). The derived dictionary is shared under the same license.

Build with `python verification/build-word-dictionary.py`.
For a fresh database, apply the schema migration, then run the optional seed generated by `python verification/build-word-dictionary.py --seed-sql` using an owner connection. `source/word-game/seed.sql` is generated locally; `dictionary.json` is the versioned derived dataset. Existing entries and played-word history are preserved on seed reruns.
Changes: retain lowercase Cyrillic nouns of 4–8 letters, normalize ё to е, deduplicate, exclude the legacy answer list and explicitly marked vulgar terms from new answers. Legacy words remain valid guesses. Reserve approximately one third of five-letter words for the non-repeating daily deck; the rest are practice answers. Difficulty changes the number of attempts (8/6/5), not word frequency. Some rare nouns remain in the source dictionary.

The daily and practice decks are disjoint. Account history is server-side and includes lost and skipped games. Deck exhaustion returns a message rather than recycling answers. Earlier browser-only results are not imported into the new verified score.
